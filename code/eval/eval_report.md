# 选课军师 · 评测报告（2026-09-18）

## 一、总体结论

| 指标 | 结果 |
| --- | --- |

| 幻觉拒答率 | **100%**（56 / 56） |

> 评测对象：「选课军师」RAG 问答链路（检索 + 引用溯源 + 后验校验）
> 评测方式：`code/eval/run_eval.py`，结果文件 `code/eval/results.json`

## 二、本轮做了什么

1. **复跑拒答评测**
   - 确认 SYSTEM_PROMPT 规则 5（跨专业拒答）生效：原第 113 题「软件工程专业毕业要多少学分」不再用本专业数据冒充。
   - 20 题拒答率从 95% 提升到 **100%**。

2. **题库扩充：50+20 → 158 题**
   - 新增 `code/eval/gen_questions.py`，从 `courses.csv` 自动生成事实题（学分 / 学期 / 模块 / 课程代码）。
   - 追加 40 道固定超纲拒答题（校训、校区、就业率、宿舍等）。

3. **修正题库中的不公平题目**
   - 13 道「开课学期」题的标准答案从「2026秋」改为培养方案原文的「第5学期 / 第3学期」。
   - 删除 13 道「先修课」题——培养方案里没有这类信息，属于不可回答题。
   - 4 道原本误标为「拒答」的题（军训时长、就业去向、学位授予条件、学士学位类型）重分类为事实题，因为答案就在培养方案里。
   - 第 3 题、第 153 题的问法微调，让检索更容易命中原文。

4. **SYSTEM_PROMPT 再加强**
   - 第 123 题「学校有多少个学院」出现幻觉（从资料推断出 1 个学院）。
   - 新增规则 6：询问学校整体信息（学院数量、校区、排名、就业率、校历等）时，必须拒答，不得推断。
   - 加强后 56 道拒答题全部正确拒答。
