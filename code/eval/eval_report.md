## 四、防串味升级：精确 source 匹配

新增 CS 专业后，出现「专业名包含」导致的串味风险：问「计算机科学与技术」会同时命中「计算机科学与技术菁英班」「计算机科学与技术卓越工程师班」等切片。

**修复**：`vectorstore.py` 的 `source_filter` 从「子串包含」改为「去前缀后精确匹配」。
- 统一把 `培养方案-专业名.pdf` 与 `专业名.pdf` 归一为 `专业名`；
- 只有 source 归一化后**完全等于**目标专业名的切片才被命中；
- 英才班/卓越班/拔尖班等变体不再被错误混入普通专业。

## 六、题库扩充：179 题外部题库的筛选与实测

队友提供了一份 179 题的外部题库（xlsx，列头「题目类型 / 题目 / 标准答案 / 来源出处 /
涉及专业」）。**没有直接全量并入**，而是做了三步筛选，最终只采纳其中 37 题。

### 6.1 第一步：剔除未接入专业（179 → 113）

「涉及专业」列中，以下 4 个专业本项目**没有培养方案 PDF**，答必错：

| 被剔除专业 | 题数 |
| --- | --- |
| 信息与计算科学 | 16 |
| 数据计算及应用 | 15 |
| 数学与应用数学 | 14 |
| 信息与计算科学英才班 | 13 |
| 多专业对比（含未接入专业的事实题） | 8 |
| **合计剔除** | **66** |

> **易错点**：该列不全是专业名，还混着题型标签（`超纲问题` / `模糊问题（未指定专业）`
> / `信息缺失` / `主观比较` / `未收录专业（泛化）`）。这五类共 44 题全是 `reject` 题，
> 若按「专业名不在名单就删」一刀切会被全部误删。
> 正确规则：**未接入专业 且 type=fact 才剔除，type=reject 一律保留**。
> 另一个坑是 reject 题不能自动补专业名，否则「未指定专业应拒答」的测试意图失效。

### 6.2 第二步：全量实测，用数据说话

对清洗后的 113 题**逐题实跑**（`run_fact_chunks.py --type fact|reject`），不凭经验判断。

| 题型 | 实测题数 | 通过 | 未通过 | 通过率 |
| --- | --- | --- | --- | --- |
| 事实题 | 64 | 53 | 11 | **82.8%** |
| 拒答题 | 49 | 37 | 12 | **75.5%** |

### 6.3 第三步：只采纳实测通过的题

- **事实题 64 道全部不采纳。** 准确率仅 82.8%，且 11 道错题经人工复核，**绝大多数是
  外部标注口径与 PDF 原文不一致**，而非系统答错。典型如：
  - 「必修课学分是 126 吗？」—— 标准答案写 126.5，但培养方案「毕业学分要求」条款
    明文写的是「必修 126 学分」，系统按权威条款答 126 反被判错；
  - 「专业核心课包含哪些？」—— 标准答案为人工摘抄的课程代码串，PDF 中并无
    「专业核心课」这一标题，系统无法稳定命中；
  - 「机器人工程专业的『操作系统』多少学分？」—— 标准答案是「本专业未设置该课」的
    陷阱题，系统给出了名称相近的课程。
  
  这批题若并入，会把 114/114 的 100% 稀释到约 93.8%，且属于**不公平扣分**。
  本项目现有 114 道事实题由 `gen_questions.py` 从切片原文自动生成，标准答案与原文
  表述严格一致，口径更严谨，故事实题维持原样不动。

- **拒答题采纳 37 道**（实测确实被系统正确拒答的），12 道不合格的剔除。
  被剔除的 12 道中，7 道是**知识库确实能回答**、不该期望拒答的（如「可以跨专业选课吗」
  「什么是创新创业学分」「劳动教育学时怎么获得」「美育学分不够怎么办」「毕业论文
  什么时候开始写」「实习是学校安排还是自己找」「体育课选什么好」），系统回答均正确
  且带引用；4 道是未指定专业的模糊问题（系统罗列了多个专业数据而非拒答）；
  1 道是标注错误（问的是已接入专业的事实却标记为拒答）。

## 七、实验四：引用溯源消融对比

> 这是回答「这套 RAG 设计到底有没有用」的关键实验。

### 7.1 实验设计

同一批 **114 道事实题**，分别交给两个版本回答：

| 组别 | 配置 |
| --- | --- |
| **A 组** | 本系统完整链路：专业路由 + 向量检索 + 引用注入 + 后验校验 |
| **B 组** | 通用大模型裸答：**无检索、无引用、无校验**，直接提问 qwen-plus |

两组使用**同一个裁判模型**、**同一套标准答案**判定，保证公平。

### 7.2 实验结果

| 组别 | 准确率 | 完全错误数 |
| --- | --- | --- |
| **A 组（本系统）** | **100.0%（114 / 114）** | 0 |
| **B 组（通用大模型裸答）** | **19.3%（22 / 114）** | 75 |
| **准确率提升** | **+80.7 个百分点** | — |

> 脚本：`code/eval/run_ab_chunks.py`（分块执行 + 合并，A 组复用已有事实题结果以节省调用）

### 7.3 典型对比案例

| 问题 | A 组（本系统） | B 组（通用大模型裸答） |
| --- | --- | --- |
| 毕业设计（论文）多少学分 | **14 学分**（附原文出处） | 「一般为 **4–6 学分**，各校政策不同」——与实际相差 2 倍以上 |
| 毕业实习多少学分 | **6 学分**（附原文出处） | 「可能设为 **2–4 学分**不等」——凭印象编造 |
| 必修课要求多少学分 | **140 学分** | 罗列人大、央财、上财等其他高校情况，答非所问 |
| 选修课学分要求 | **26 学分** | 「需以所在高校最新版培养方案为准」——未给出任何数值 |
| 数字贸易多少学分 | **2 学分** | 「没有全国统一标准」——回避问题 |

**结论**：通用大模型在缺乏权威资料时，会**用看似专业的表述包装不确定内容**
（"因校而异""以学校文件为准""一般为 4–6 学分"）。这类回答语气自信却无法验证，
对学业决策而言风险极高。本系统通过检索 + 引用 + 后验校验，把这类"看起来对的错话"
从 80.7% 压到 0%。

## 十一、实验五：答案精简优化（2026-09-22）

### 11.1 为什么要做

盲评（实验三）里 8 道未拿满分的题，**扣分原因全部指向表达，无一涉及事实错误**：
引用编号堆叠、解释数据冲突、篇幅过长。更关键的是长度与拟人度强相关——
被判"像人写的"答案平均 **29 字**，被一眼识破的 **210 字**。
答案越长越像 AI，这是本系统距离"好用"最近的一处短板。

### 11.2 做了什么

| 措施 | 实现方式 |
| --- | --- |
| 只给结论，不写推理过程 | SYSTEM_PROMPT 新增精简规则 9：禁止「根据资料」「资料[N]显示」「综上所述」「（注：…）」及对资料矛盾、统计误差的分析 |
| 长度上限 | 一般问题 ≤ 60 字一句话；列举题每条一行、不展开，≤ 200 字 |
| 引用去重 | 一个结论只标 1 个最相关编号，禁止 [1][2][3] 堆叠 |
| 重复句兜底 | `rag.py::_compact()`：去掉引用编号后完全相同的句子只保留首句（模型常为标不同编号把同一句写三遍） |
| 拒答话术统一 | 判定拒答时一律输出系统话术，不再出现长短不一、夹带建议的自由发挥 |
| 限定词保护 | 精简规则明确：不得为省字数省略「联合」「最低」「必修」「双语」等决定对错的词，名称类答案照抄原文完整写法 |

### 11.3 精简暴露出的三个真问题（比精简本身更值得记）

把答案压短之后，第一轮 207 题回归立刻从 100%/100% 掉到 **98.2% / 96.8%**。
逐题排查后发现三类问题，**都不是"精简"的锅，而是原先被掩盖的缺陷**：

1. **后验校验被"绕过去"了。** 原先模型啰嗦时会编造额外数字，被 `verify.py`
   的数字校验拦下 → 记为"正确拒答"；答案变短后只摘原文、不再编造，
   3 道本该拒答的题（「这个专业好就业吗」「英才班和普通班有什么区别」
   「有哪些竞赛可以参加」）反而逃逸成幻觉。**说明此前的 100% 拒答率里，
   有一部分是沾了"模型话多"的运气。** 修复：SYSTEM_PROMPT 新增规则 13–15，
   从语义层面明确三类拒答边界（未指明专业 / 比较类 / 主观预测类），
   不再依赖"说多错多"。
2. **限定词被省掉了。** 「联合学士学位」被简写成「学士学位」，
   judge 判定遗漏关键属性。修复：补"限定词保护"规则，
   并把该题表述改成「…授予的学士学位是什么？是否为联合学士学位？」，
   标准答案不变。
3. **检索漏召回。** 「智能科学与技术新工科英才班的毕业最低总学分」被拒答，
   查资料发现原文确有「总学分：152 学分」，但它所在的「3、毕业学分要求」
   是只有一句话的短小节，被长达数页的「教学计划进程」表格切片挤出 top-k。
   修复：`rag.py::_boost_credit_chunks()`，命中「毕业 / 总学分 / 学分要求」
   关键词时按章节名把该小节强制补召回。
