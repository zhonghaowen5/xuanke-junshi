## 一、项目简介

大学生从入学到毕业，要面对一套复杂规则：培养方案、学分构成、必修选修比例、先修课要求、毕业审核条件。这些规则写在几十上百页的 PDF 里，分散在教务处网站、学院通知、班级群中。

**选课军师** 基于 RAG（检索增强生成）技术，把重庆邮电大学各专业的本科培养方案 PDF 结构化后接入大模型，让学生可以用自然语言提问，获得可溯源、可验证的回答，并能基于成绩单诊断学分缺口、推荐下学期课程。

项目参加 **2026 年第二届重庆市 AI 大模型创新应用大赛**，企业出题赛道，阿里出题「创意 AI 校园」。

## 二、核心功能

| 功能 | 说明 | 示例问题 |
|---|---|---|
| **📚 培养方案问答** | 基于官方培养方案 PDF 回答，每条答案都带原文出处 | 「软件工程专业毕业要修多少学分？」 |
| **🎯 学分诊断** | 上传成绩单 CSV，自动比对培养方案规则，计算缺口 | 「我现在还差多少学分能毕业？」 |
| **🗓️ 选课建议** | 根据已修课程、先修课要求、学分缺口推荐下学期课程 | 「2026 秋我应该优先选哪几门课？」 |

## 三、快速开始

### 3.1 环境要求

- Python 3.10+
- 阿里云百炼 API Key（用于 qwen-plus 与 text-embedding-v3）
- Windows / macOS / Linux 均可

### 3.2 一键配置（推荐）

```bash
cd code
python setup.py
```

脚本会：
1. 检查 Python 版本
2. 安装缺失依赖
3. 提示输入阿里云百炼 API Key
4. 验证对话模型与向量模型是否可用

### 3.3 启动 Streamlit 前端

```bash
cd code
python -m streamlit run app.py
```

浏览器会自动打开 `http://localhost:8501`。侧边栏选择专业后，即可在三个标签页中问答、诊断、获取选课建议。

> 详细图文步骤见 [`docs/用户操作手册.md`](docs/用户操作手册.md)。

## 四、数据与评测

### 4.1 知识库覆盖

- **20 份培养方案 PDF**（人工智能学院 12 份 + 计算机科学与技术学院 8 份）
- **755 个文本切片**，按章节标题切分并标注 `source / chapter / page`
- **16 个专业**的现行培养方案学分规则表
- **1454 门课程**开课数据（用于学分诊断与选课建议）

### 4.2 防幻觉机制

| 层级 | 做法 |
|---|---|
| **路由层** | 问题提及专业时，只在对应专业切片内检索，防止跨专业「串味」 |
| **检索层** | 最高相似度低于阈值直接拒答 |
| **生成层** | 温度 0.1，强制「只能用给定资料」并标注来源 |
| **校验层** | 答案中的数字、课程名回召原文核验，不通过即降级为拒答 |

### 4.3 评测结果

使用 [`code/eval/run_eval.py`](code/eval/run_eval.py) 在 207 题题库上评测：

| 指标 | 结果 |
|---|---|
| 事实准确率 | **100%（114 / 114）** |
| 幻觉拒答率 | **100%（93 / 93）** |

> 完整评测报告见 [`code/eval/eval_report.md`](code/eval/eval_report.md)。

## 六、技术栈

- **大模型**：阿里云百炼 qwen-plus
- **向量模型**：阿里云百炼 text-embedding-v3（1024 维）
- **检索**：numpy 余弦相似度 + Top-K 召回
- **前端**：Streamlit
- **数据**：pandas、pdfplumber
- **版本控制**：Git + GitHub

## 八、注意事项

1. **API Key 安全**：运行 `setup.py` 时输入的 Key 会写入 `code/.env`，该文件已被 `.gitignore` 忽略，不会进入仓库。
2. **成绩单隐私**：`transcript-*.csv` 类型的成绩单文件已被 `.gitignore` 忽略，不会提交到 GitHub。
3. **数据更新**：培养方案每年可能微调，使用者可将新版 PDF 放入 `code/data/raw/` 后重新运行 `ingest.py` 与 `vectorstore.py build` 更新知识库。
