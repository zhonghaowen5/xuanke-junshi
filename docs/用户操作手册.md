# 选课军师 · 用户操作手册

> 适合第一次使用本系统的同学。不需要懂代码，照着点就行。

---

## 一、启动系统

### 第一步：打开黑窗口（命令提示符）

按 `Win + R`，输入 `cmd`，按回车。

### 第二步：粘贴命令启动

复制下面这一整行，在黑窗口空白处点右键粘贴，然后按回车：

```cmd
python -m streamlit run "C:\Users\zhong\WorkBuddy\2026-09-17-16-19-59\逐光队-选课军师\code\app.py"
```

稍等几秒，浏览器会自动弹出页面 `http://localhost:8501`。

> 如果浏览器没自动弹，就在地址栏手动输入 `localhost:8501`。

### 第三步：在浏览器里使用

页面打开后，左侧是专业选择区，右侧是主功能区。

---

## 二、界面说明

### 左侧边栏

- **专业选择**：点击下拉框，选择你自己的专业。
- **毕业要求总学分**：系统会根据所选专业自动显示毕业需要修满的总学分。

> 年级不再手动选择，系统默认采用现行培养方案（目前为 2024 级版本）。

### 右侧主区

有三个标签页：

1. **📚 方案问答** — 问培养方案里的任何问题
2. **🎯 学分诊断** — 上传成绩单，看还差多少学分
3. **🗓️ 选课建议** — 推荐下学期该选哪些课

---

## 三、📚 方案问答

### 直接提问

在输入框里打字，比如：

- 「软件工程专业毕业要修多少总学分？」
- 「数据科学与大数据技术专业的选修课要修满多少分？」
- 「计算机科学与技术专业的实践环节包含哪些内容？」

点击「提问」，系统会：

1. 先检索你左侧选中的专业培养方案；
2. 用 AI 给出回答；
3. 在回答下方显示「📎 查看原文出处」，点开可以看到答案来自哪份 PDF、哪个章节、第几页。

### 示例问题按钮

页面上方有几个蓝色示例按钮，不知道问什么时点一下，会自动填到输入框里。

### 「仅查询左侧选中的专业」开关

- **开启**（默认）：如果你没写专业名，系统自动按左侧选中的专业回答，避免串到其他专业。
- **关闭**：适合问跨专业对比问题，比如「英才班和普通班的学分要求有什么区别？」。

## 四、🎯 学分诊断

### 准备成绩单

1. 点击「📥 下载成绩单模板（用 Excel 照着填）」。
2. 用 Excel 打开模板，把自己的课程填进去：
   - 课程代码
   - 课程名称
   - 学分
   - 所属模块（只能填「必修课」或「选修课」）
   - 学期
   - 成绩（数字或「通过」都可以）
3. 填好后，在 Excel 里点「文件」→「另存为」→ 文件类型选「CSV（逗号分隔）(*.csv)」，保存。

### 上传并诊断

1. 回到「选课军师」页面，点击「Browse files」或把 CSV 文件拖到上传框里。
2. 看到「已读取 X 门课程」后，点击「开始诊断」。
3. 等待几秒，你会看到：
   - 毕业要求总学分
   - 已修学分
   - 待修学分
   - 每个模块的达成率进度条
   - 风险提示（比如必修课还差多少分）

> 不上传成绩单也可以使用系统，会自动使用内置演示数据。

## 五、🗓️ 选课建议

### 使用步骤

1. 确认左侧已选好你的专业。
2. 如果你上传了成绩单，系统会自动用它判断先修课是否通过。
3. 在「学期」框里输入你想规划的学期，比如 `2026秋`。
4. 点击「生成建议」。
5. 系统会列出推荐课程，并说明推荐理由：
   - 是必修课，优先完成
   - 所属模块还缺多少学分
   - 之前未通过，需要重修

> 如果该专业暂无对应学期的开课数据，页面会提示。

### 导出学业规划报告

生成选课建议后，页面底部会出现：

**「📄 导出个人学业规划报告（HTML，可打印为 PDF）」**

点击后会下载一个 `.html` 文件。用浏览器打开它，按 `Ctrl + P`，
在打印目标里选「另存为 PDF」，就能得到一份完整的学业规划报告，包含：

- 毕业要求总学分 / 已修 / 待修 / 完成度
- 每个模块的达成率条形图
- 风险提示
- 下学期推荐课程表与推荐理由

> 也可以直接在「学分诊断」页点「导出学分诊断报告」，只导出诊断部分。
> 示例文件见 `docs/示例-学业规划报告.html`。

## 六、常见问题

| 问题 | 原因 | 解决办法 |
|---|---|---|
| 启动时报错 `No module named streamlit` | 依赖没装好 | 重新运行 `python "C:\Users\zhong\WorkBuddy\2026-09-17-16-19-59\逐光队-选课军师\code\setup.py"` |
| 提问后一直转圈 | 网络或模型调用慢 | 等 10–20 秒；如果还不出，刷新页面再试 |
| 回答显示「超出了我掌握的培养方案范围」 | 问题不在知识库里，或专业没选对 | 检查左侧专业是否正确；换个问法 |
| 诊断结果显示「规则表中没有匹配的专业/年级」 | 左侧专业没有对应的培养方案规则 | 换一个有数据的专业 |
| 选课建议为空 | 该专业该学期没有开课数据，或先修课未通过 | 换个学期，或检查成绩单里的先修课成绩 |
| 上传成绩单报错 | CSV 格式不对 | 严格使用系统提供的模板，模块只能填「必修课」或「选修课」 |

## 七、安全提示

- 你自己的 API Key 已经存在 `code/.env` 文件里，**不要把这个文件发给别人**。
- 成绩单里有你的学号、成绩等隐私信息，系统默认**不会**把它提交到 GitHub；用完可以删除本地 CSV。
- 不要把 API Key 截图发到群聊或社交平台。
